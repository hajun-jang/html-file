업로드되는 파일명은 마인크래프트 허용 문자(소문자, 숫자, 점, 밑줄, 하이픈, 슬래시) 범위로 그대로 깔끔하게 치환됩니다.
CLOUDINARY_URL을 입력하면 계정 키와 서명이 자동 계산됩니다.
Cloudinary 설정에서 Unsigned preset으로 생성한 이름을 입력하세요.
체크 시 Cloudinary 저장 URL에 수정된 파일명이 반영됩니다.

마인크래프트 지도 파일 / 이미지를 드래그 앤 드롭하세요

지도 이미지 (.png, .jpg, .webp 등) 및 지도 데이터 파일 (.dat 등) 모두 업로드 가능합니다.
